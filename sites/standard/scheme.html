kn-media · по умолчанию

KINOR.MEDIA

kinor.media · зонтичный дом

тёмное 25%
светлое 75%

Характер. Спокойный, строгий, редакционный. Серебро не спорит с проектами — их цвета появляются только в карточках проектов и в футере.

Анатомия hero. Светлый фон light. Слева (7/12): eyebrow, H1-девиз, lead, две кнопки, три чипа-лада (первый — тёплый). Справа (5/12): тёмная карточка night, радиус 28, поле струн data-ramp=flat, тёплая струна на 84% ширины, подпись Cormorant внизу слева (не пересекает струну).

Девиз. «Медиа открывает дверь. Люди — наша миссия.» — неразрывный пробел перед тире.

Кнопки. На светлом: primary — фон accent-ink, текст белый; ghost — рамка hair-light. На тёмном: primary — фон accent, текст night.

Одна тема kinor-media — два проекта

Проект = класс на body. Цвет = токены.

Разметка и компоненты ссылаются только на переменные (--accent, --light…), никогда на названия палитр. Смена палитры — правка одного файла tokens.css.

kinor-media/                 Ghost theme
├─ default.hbs               body class ← block "project"
├─ index.hbs · post.hbs · page.hbs · tag.hbs · author.hbs
├─ custom-conf26.hbs         лендинг, {{!< default}} + kn-conf
├─ partials/  header · footer · hero-strings · card-post
│             card-project · faq · interest-form · k-mark
├─ assets/css/tokens.css     ← kinor-web-tokens.css
├─ assets/css/theme.css      поверхности, компоненты
├─ assets/js/strings.js      ← kinor-strings.js
├─ assets/fonts/             Onest, Cormorant (woff2)
└─ routes.yaml · package.json (config.custom)
# routes.yaml
routes:
  /conf26/:
    template: custom-conf26
    data: page.conf26
collections:
  /:
    permalink: /{slug}/
    template: index
    filter: tag:-hash-conf26
{{!-- default.hbs --}}
<body class="{{body_class}} {{{block "project"}}}">

{{!-- custom-conf26.hbs --}}
{{!< default}}
{{#contentFor "project"}}kn-conf{{/contentFor}}

Домен. conf26.kinor.media — 301 или прокси на kinor.media/conf26/ (ADR-008). Без класса body = KINOR.MEDIA.

Данные. Ghost Members — рассылки и доступ к материалам. Люди, согласия, отклики и форма F0 — Supabase / Relationship OS. React/Vite — только для прикладных частей.

Синтаксис helpers проверить на целевой версии Ghost; архитектор вправе выбрать другой способ, если сохраняется принцип «класс проекта → токены».

Что стабильно · что меняется

Стабильно: разметка, сетка, компоненты, знак и тёплая струна, шрифты, поведение поля струн, имена классов проектов (kn-media, kn-conf, kn-school, kn-labs).

Может измениться: значения --accent, --accent-ink, --light, --light-2, фон страницы проекта. Проверка контраста — при каждой смене.

Не делать: тёплый цвет в кнопках и ссылках; холодные светлые фоны для конференции; несколько тёплых струн на экране; цвета проектов вне карточек проектов и футера.

Качество

  • WCAG 2.2 AA: текст ≥ 4.5:1, крупный ≥ 3:1; фокус видим
  • Адаптив: 390 · 768 · 1024 · 1440; поля ≥ 16 px; без горизонтального скролла
  • prefers-reduced-motion → статичные струны
  • Canvas: DPR ≤ 2, пауза вне экрана и во фоновой вкладке
  • LCP < 2.5 s на 4G; шрифты self-host, font-display: swap
  • Картинки: responsive srcset от Ghost, lazy ниже первого экрана
  • OG-картинки 1200×630 для каждого шаблона
  • До утверждения — noindex и закрытый доступ
