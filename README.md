# KINOR MediaConference 2026 — дизайн-концепт «Струна» (направление A)

Статический прототип лендинга для обсуждения визуального направления. **Черновик — не официальная страница конференции.**
Форма интереса работает в демо-режиме и никуда не отправляет данные. Страница закрыта от индексации (`noindex`).

- `index.html` — лендинг (HTML/CSS/canvas, без сборки)
- `og.png` — превью для мессенджеров и соцсетей
- `img/` — схемы дизайн-системы и скриншоты для отчёта
